## Controls / 操作方法

- **W, A, S, D** — Move / 移動（上・左・下・右）  
- Move cursor to **Aim** / マウスカーソルで照準  
- Right click to **Attack** / 右クリックで攻撃  
- **1, 2, 3, 4, 5** — Switch Weapons / 武器切替  

---

## Weapons / 武器一覧

- **Sword / 剣** — Low Damage, Low Cooldown / 低ダメージ・低クールダウン  
- **Staff / 杖** — Ranged, can bypass walls and ponds / 遠距離攻撃、壁や池を貫通可能  
- **Bow / 弓** — Ranged, cannot bypass walls and ponds / 遠距離攻撃、壁や池は貫通不可  
- **Broadsword / 大剣** — Very High Damage, Very High Cooldown / 高ダメージ・高クールダウン  
- **Gold Gun / ゴールドガン** — Spend coins to fire shots / コインを消費して射撃  

---

## Enemy Type / 敵一覧  
**WARNING: CONTAINS SPOILERS / ネタバレ注意**

### Normal Enemy / 通常敵

- **Slime / スライム** — Your most common enemy, attacks by approaching / 最も一般的な敵。近づいて攻撃する  
- **Ghost / ゴースト** — Ranged enemy, shoots bullets / 遠距離攻撃タイプ。弾を撃つ  
- **Purple Slime / 紫スライム** — Throws globs from above, can bypass walls / 上空から弾を落とし、壁を貫通可能  

### Bosses / ボス

- **Crystal Knight / クリスタルナイト** — Shoots a curtain of bullets / 弾幕を放つ遠距離ボス  
- **Slime Queen / スライムクイーン** — Shoots globs, defeated after ten attacks / 粘液弾を放つ。10回攻撃後に撃破  
- **Slime King / スライムキング** — Shrinks and spawns behind player / 縮小してプレイヤー背後に出現する近接ボス  
- **Demons / デーモン** — Melee bosses, 1v4 battle / 近接型ボス、1対4戦闘
